# Kasa LMS - Next.js Version

This is the static Next.js version of the Kasa LMS theme.

## Run

```bash
bun install
bun run dev
```

Open `http://localhost:3000`.

## Build

```bash
bun run build
```

## Data

Demo data is local and static:

```txt
lib/static-api.ts
```

No separate app, database, Docker setup, CI workflow, or deployment script is required for this version.
