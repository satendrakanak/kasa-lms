KASA LMS Documentation

KASA LMS is a modern Next.js Learning Management System and Admin Dashboard theme with static demo data, responsive layouts, learner dashboards, faculty dashboards, admin screens, course pages, checkout flow, articles, testimonials, and component demos.

Package Contents

  • source/nextjs-version - complete Next.js theme source.
  • documentation - this setup and customization guide.
  • themeforest-preview - screenshots, marketplace copy, and preview reference.

Requirements

  • Node.js 20 or newer recommended.
  • Bun package manager recommended because the project includes bun.lock.
  • A modern browser for testing light and dark mode.

Installation

cd source/nextjs-version
bun install
bun run dev

Open http://localhost:3000 in your browser.

Production Build

cd source/nextjs-version
bun run build
bun run start

Static Demo Data

The theme uses static data and adapter services for preview mode. Most demo content, courses, articles, faculty, testimonials, coupons, orders, admin records, learner progress, and dashboard data live in source/nextjs-version/lib/static-api.ts.

Logo and Branding

Main logos and app icons are stored in source/nextjs-version/public/assets. You can replace kasa-logo-light.png, kasa-logo-dark.png, favicon, and PWA icons with your own brand assets.

Theme Modes

Light and dark mode are included. Theme handling is inside source/nextjs-version/components/theme/theme-provider.tsx.

Vercel Deployment

cd source/nextjs-version
npx vercel --prod --yes

Demo URL used for marketplace preview: https://kasa-lms.vercel.app/

Included Major Pages

  • 5 homepage demos
  • Course catalog and single course pages
  • Cart drawer, cart page, and checkout page
  • Learner dashboard, courses, classes, exams, certificates, profile, settings, and orders
  • Admin dashboard, course management, articles, coupons, categories, users, orders, refunds, media, roles, settings, and more
  • Faculty dashboard, faculty courses, classes, students, exams, recordings, and calendar
  • Articles, testimonials, about, contact, faculty listing, faculty details, and UI component demos
